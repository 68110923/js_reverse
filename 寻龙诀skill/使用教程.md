## 📦 `xunlongjue` Skill 结构
```
~/.hermes/skills/deploy/xunlongjue/
├── SKILL.md                    ← 部署指南+策略参数+回测成绩
├── scripts/
│   ├── morning_push.py         ← 早盘选股 v4.1
│   ├── afternoon_review.py     ← 收盘复盘
│   ├── market_signal.py        ← 大盘预测
│   ├── hermes_stock_lib.py     ← 共享函数库
│   └── init_db.py              ← 一键建库
└── references/
    └── pitfalls.md             ← 完整踩坑记录
```
### 部署只需 4 步
```bash
# 1. 装依赖
pip install akshare requests

# 2. 复制脚本
cp ~/.hermes/skills/deploy/xunlongjue/scripts/*.py ~/.hermes/scripts/

# 3. 初始化数据库
python3 ~/.hermes/scripts/init_db.py

# 4. 设置 Cron
hermes cron add --name "寻龙诀早盘" --schedule "26 1 * * 1-5" --script morning_push.py --no-agent
hermes cron add --name "寻龙诀复盘" --schedule "30 7 * * 1-5" --script afternoon_review.py --no-agent
hermes cron add --name "大盘预测" --schedule "20 7 * * 1-5" --script market_signal.py --no-agent
```
### 分享方式
把 `~/.hermes/skills/deploy/xunlongjue/` 整个目录打包发给朋友，朋友放入自己的 `~/.hermes/skills/deploy/` 目录后，对 Hermes 说「加载 xunlongjue skill」即可看到完整文档和部署步骤。


```
hermes skill install xunlongjue.tar.gz
```
